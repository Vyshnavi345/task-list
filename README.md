# 📝 Task List App

A minimal React application that allows users to:

- Add tasks dynamically using a "+" button  
- Display tasks immediately as they are added  
- Automatically clears the task list after submission   

This is a frontend-only project, built for demonstration purposes.

---

## 🛠️ Tech Stack

- **React** (via `create-react-app`)
- **HTML + CSS + JavaScript**

---

## 📦 Installation & Setup

1. **Clone the repository**  
```bash
git clone https://github.com/Vyshnavi345/task-list.git
cd task-list

npm install

npm start
```
